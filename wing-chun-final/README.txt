Wing Chun: Siu Nim Tau - Interactive 3D Website

This version uses the faculty-provided movement timing and a simplified single-card interface.

SETUP
1. Put the final animated GLB at:
   models/wing-chun.glb
2. Open this folder in Visual Studio Code.
3. Use the Live Server extension and open index.html with Live Server.

INTERFACE
- Left side: current movement name, number, and description.
- Right side: interactive 3D model.
- Bottom of the same card: timeline, Previous / Play-Pause / Next, movement dropdown, and nearby movement navigation.
- The current movement is highlighted automatically while the animation plays.
- Playback uses the original animation speed.

3D CONTROLS
- Rotate: click + drag
- Zoom: mouse wheel / scroll
- Pan: right-click + drag

MODEL NOTE
The website uses neutral environment lighting, soft shadows, and controlled exposure. If the character is rotated, offset, deformed, or incorrectly centered, correct the GLB export in Blender rather than trying to compensate in the webpage.
